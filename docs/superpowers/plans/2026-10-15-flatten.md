# Flatten integration

Goal: add Tensor.flatten(start_dim=0,end_dim=-1) and parameter-free
nn.Flatten(start_dim=1,end_dim=-1), composing existing checked reshape.

Semantics: inclusive normalized axes; reject booleans/nonintegers, out-of-range
axes and reversed intervals. Scalar axes use effective rank one and reshape to
(1,). A non-scalar single-axis flatten returns the original Tensor. Collapsed
sizes use Python integer arithmetic then existing platform-size validation.
Contiguous inputs share storage; noncontiguous inputs use existing reshape copy.
Bool tensors retain bool dtype. No new native kernel or compiler capture.
