# Shared tensor storage implementation plan

**Goal:** Introduce checked CPU float32 layouts and immutable shared storage while preserving eager, autograd, compiled execution and checkpoint behavior.

**Architecture:** TensorData contains TensorStorage (Arc-owned immutable buffer), TensorLayout (shape, element strides, offset), and a shared lazy logical-values cache. Existing kernels consume values() in logical row-major order. Contiguous inputs borrow storage; strided inputs materialize once. Parameter replacement remains snapshot based with existing logical version counters. Storage identity is separate from Node and logical parameter identity.

**Constraints:** CPU float32 only. No in-place writes. No unsafe Rust. Preserve stable history and user files. No push, tags or publication. Version numbers do not imply completed releases.
